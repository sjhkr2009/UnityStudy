Time 노드
- 애니메이션 효과, 시간 기반으로 반복되는 효과에 사용

- Time : 게임 실행 후 경과한 시간 (초)
- Sine/Cosine Time : 사인/코사인 함수와 동일한 주기적인 값 제공
- Delta Time : 게임 내 프레임 간격 시간

UV 노드
- 이미지의 기준 좌표인 (U,V) 좌표에 대한 정보를 제공한다
 ㄴ 좌측 하단을 (0,0), 우측 상단을 (1,1)로 간주하는 좌표
- 기본적으로 Input이 없고, Output을 Tiling And Offset 노드에 연결해 기준 좌표를 가공한다

Tiling And Offset
- Tiling : 텍스쳐의 반복 횟수 설정
- Offset : 텍스쳐의 좌표 이동 설정

Sample Texture 2D
- 텍스쳐를 입력받고, 입력된 UV에 따른 색상 값을 반환한다.
- Sampler(SS) 입력으로 샘플링 방식을 설정할 수 있는데 이는 추후에 다루기로
 ㄴ 여러 가지가 있는데 일단 Sampler State 기본값을 사용한다.

Fresnel Effect
- 지표면 반사. 물체가 보이는 방향 기준으로 외곽선에 가까울수록 선명하게 보인다.
- 투명도가 있는 물체가 외곽 부분이 더 잘 보이게 하는 효과. Emission에 연결해서 사용한다.

Step 노드
- 입력된 값이 Edge보다 크면 1, 아니면 0을 반환한다.

SmoothStep 노드
- 입력된 값이 Edge1보다 작으면 0, Edge2보다 크면 1, 그 사이에 있으면 0~1 사이의 보간 결과를 반환한다.

Remap
- 입력된 값을 In Min Max 사이로 보간해서, 해당 보간 결과를 Out Min Max 사이로 변형해서 반환한다.
- 값의 범위를 변경할 때 사용한다. (ex: 0~1 사이의 값을 -10~10 사이로 변경)

Rectangle 노드
- 사각형 형태의 모양을 그린다.
- UI 버튼의 외곽선 표기에도 사용되고, UV를 왜곡시키는 Noise와 결합해서 랜덤한 이미지를 그릴 때도 사용한다.

Position 노드
- 오브젝트의 Transform의 포지션을 반환한다. 좌표계를 선택할 수 있다.

Twirl 노드
- 소용돌이 모양의 UV 좌표

Screen Position 노드
- 화면에 렌더링되는 모든 픽셀의 위치를 좌하단 (0,0) ~ 우상단 (1,1) 사이로 반환한다.
- Raw 모드일 경우 정규화되지 않은 (-w,-w) ~ (w,w) 값을 반환한다. w는 카메라와 해당 픽셀의 거리가 된다.
- Default든 Raw든 해당 노드의 a 채널에는 카메라와의 거리가 반환된다. (rgb 채널은 xyz 좌표)

Scene Depth 노드
- 렌더링된 화면의 깊이 값을 반환한다. 샘플링 모드에 따라 반환값이 달라진다.
 ㄴ Screen Position과 달리 화면에 보이는(=카메라에 제일 먼저 닿는) 픽셀 기준이므로, 다른 오브젝트가 앞에 있으면 해당 픽셀까지의 거리가 반환된다.
 ㄴ 달리 말해 Screen Position의 알파 채널과 이 값이 다르다면, 다른 오브젝트를 보고 있는 것.
- Linear01은 카메라의 Near~Far 영역을 0~1 로 간주해서 물체의 상대적인 거리를 반환한다. 그림자, 마스크, 안개 등에 사용.
- Raw는 카메라의 Near~Far 영역을 원근법이 적용된 0~1 사이로 반환한다. Linear01에 비해 가까운 곳의 거리 차이를 더 크게 계산한다.
- Eye는 월드 좌표 기준으로 카메라와의 실제 거리를 반환한다. (0~1 범위 아님) 거리 계산이 필요할 때 쓴다.

Scene Color 노드
- UV 좌표를 입력받아, 현재 카메라에 렌더링된 해당 픽셀의 색상 정보를 반환한다.
- 주로 Screen Position 노드 및 해당 노드의 가공된 UV 좌표를 넘겨서 색상 정보를 추출할 때 쓴다.

Normal Vector 노드
- 이 오브젝트의 표면의 법선 벡터를 반환한다.

Dot Product 노드
- 두 벡터의 내적을 반환한다.
- 두 벡터의 방향이 얼마나 비슷한지 체크할 때 주로 사용한다.
- Normal Vector와 (0,1,0) 벡터를 넣어서 오브젝트가 얼마나 위로 향해 있는지 체크하는게 대표적인 예시

Saturate 노드
- In 값을 0~1 사이의 범위로 제한한다
- Clamp(0,1) 과 동일하나 좀더 가벼운 동작

One Minus
- 1에서 In을 뺀 값을 반환한다

Normal From Height
- 0~1 사이의 입력값을 받아서, 주변 픽셀과의 값 차이를 기울기로 간주하고 이를 바탕으로 노말 벡터를 반환한다.
- Strength 값을 계수로 사용한다. 즉 이 값이 높을수록 주변 픽셀과의 값 차이를 더 민감하게 반응해 거칠고 날카로운 표면을 묘사한다.

* PointLight 셰이더에서 빛의 감쇄(빛과의 거리에 따라 빛이 감소하는 양) 값은 [ 1 / (거리^2) ] 이다.
* Wave2 셰이더에서 파동 방정식을 사용한다. Sin(Distance * Frequency - Time * Speed) * Amplitude = 결과값이 된다.
* Distortion 셰이더와 같이 빛의 영향을 안 받고 뒤쪽 픽셀에 대한 가공만 하는 경우 Unlit 셰이더로 생성, 투명도가 있다면 Transparent도 지정해준다.
* Skybox 셰이더에서 정규화된 포지션을 수평 좌표(x,z)를 수직 좌표(y)로 Divide하는 부분은, 수평 좌표를 높이에 따라 보정하는 부분이다.
  ㄴ 지평선에 가까울수록 x,z 값이 커져서 텍스쳐가 더 늘어나 역동적으로 보이고, 멀수록 x,z값의 편차가 줄어서 더 잔잔해진다.
* Water 셰이더에서 Scene Depth로 물 뒤쪽 객체의 깊이를, Screen Position으로 물 자체의 픽셀 깊이를 구해서, 이 차이로 물의 깊이를 계산한다.
